# Drum Kit 🎶

A fun and interactive drum kit web application that allows users to play six different drum sounds either by clicking on the on-screen drum buttons or by pressing specific keys on the keyboard.

## Features

- 🎵 **Interactive Sounds**: Play six different drum sounds.
- 🎮 **Keyboard Control**: Press designated keys to play the drum sounds.
- 🖱️ **Click-to-Play**: Click on the on-screen drum buttons for the same experience.
- 💻 **Responsive Design**: Works seamlessly across devices with modern browsers.
